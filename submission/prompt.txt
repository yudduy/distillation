You are deciding whether law A (Eq1: {{ equation1 }}) implies law B (Eq2: {{ equation2 }}) over all magmas.

A magma is a set with one binary operation * and no axioms. Variables are universally quantified. "A implies B" means every magma that satisfies A for all assignments also satisfies B for all assignments. Two facts drive everything below:
(1) FALSE is proved by ONE magma that satisfies A but fails B.
(2) TRUE is proved when B is a syntactic consequence of A, or when A is so strong that only a one-element magma satisfies it.
(3) When no listed magma separates A from B and no syntactic rule applies, the fallback in Step 4 gives the verdict from the shape of A; that is the intended default, not a guess.
Apply the steps in order and STOP at the first rule that fires. Do every check explicitly from the parsed fields; never invent a magma that is not listed here.

OUTPUT FORMAT: write the PARSE block and a short rule trace, then end with EXACTLY these four lines, no markdown, nothing after COUNTEREXAMPLE:
VERDICT: TRUE or FALSE
REASONING: one rule name from {X1 X3 X4 F1 F2 F3 F4 F5 C0 LP0 LP2 LP3 RP0 RP2 RP3 SET PARITY W1 W2 W3 W4 B1 B2a B2b B2c}
PROOF: one short sentence if VERDICT is TRUE, otherwise empty
COUNTEREXAMPLE: one short sentence if VERDICT is FALSE, otherwise empty

=== STEP 0 - PARSE (mandatory, write it before any rule) ===

For each of the four sides A.L, A.R, B.L, B.R write one line:
  PARSE <side>: shape=<fully parenthesized>  vars={..}  occs={v:k,..}  op=<n>  bare=<Y/N>  lm=<v> ld=<n>  rm=<v> rd=<n>
Read the side as a binary tree; every * is a node. Input may be written with spaces around * (x = y * x); spacing means nothing.
  op = number of * on this side. bare = Y iff the side is a single variable (op = 0).
  lm = leftmost leaf; ld = number of * nodes on the path from the root to lm (always taking the left child).
  rm = rightmost leaf; rd = number of * nodes on the path from the root to rm (always taking the right child).
  A bare side v has lm=rm=v and ld=rd=0.
Example x*(y*x): shape=(x*(y*x)) vars={x,y} occs={x:2,y:1} op=2 bare=N lm=x ld=1 rm=x rd=2.
Example (x*y)*(z*x): lm=x ld=2 rm=x rd=2.

Then write LEAVES <side>: every leaf occurrence with (L,R) = number of left branches and right branches on its path from the root.
Example (x*y)*(z*x): x(2,0) y(1,1) z(1,1) x(0,2). Example x*(y*x): x(1,0) y(1,1) x(0,2). Bare v: v(0,0).

=== STEP 1 - TRUE BY SYNTAX ===

X1: B.L and B.R are the same string -> TRUE.
X3: A has a bare side whose variable does not occur on the other side (e.g. x = y*z, x = y*(z*y)) -> TRUE. Such an A forces all elements equal, so every law holds.
X4 (instance): B is A with terms substituted for A's variables, the same term at every occurrence of that variable, possibly after swapping A's two sides. Check: overlay A.L on B.L and A.R on B.R node by node from the root; a * node of A must land on a * node of B; a variable of A may land on any subterm of B but must land on the same subterm every time. If it works, or works with A's sides swapped -> TRUE. Renaming variables is a special case. Example: A: x*y = y*x, B: (x*z)*y = y*(x*z): x->(x*z), y->y, TRUE. Direction matters: A being an instance of B proves nothing.

=== STEP 2 - PROJECTION LAWS (decide either way) ===

In F1-F5, x, y, u, v, w stand for SINGLE variables (not subterms); "up to renaming and side swap" is allowed. x = x*(x*y) is NOT F1.
F1: A is x = x*y with x != y. Then a*b = a in every model, so every term equals its lm. TRUE iff lm(B.L) = lm(B.R), else FALSE.
F2: A is x = y*x with x != y. Then a*b = b. TRUE iff rm(B.L) = rm(B.R), else FALSE.
F3: A is u*v = u*w with u, v, w single variables and v != w (e.g. x*y = x*z, x*x = x*y). Then a*b = f(a) for an arbitrary function f, so a term equals f applied ld times to lm. TRUE iff (lm, ld) of B.L equals (lm, ld) of B.R, else FALSE.
F4: A is v*u = w*u with v != w (e.g. x*y = z*y, x*x = y*x). Then a*b = g(b). TRUE iff (rm, rd) of B.L equals (rm, rd) of B.R, else FALSE.
F5: one side of A is u*v with u != v single variables, and the other side is a product containing neither u nor v (e.g. x*y = z*w, x*x = y*z, x*y = z*(w*z)). Then every product equals one constant. TRUE iff neither side of B is bare, else FALSE.

=== STEP 3 - SEPARATING MAGMAS (FALSE) ===

Each test names a magma and the exact condition under which a law holds in it. Compute the condition for A and for B. If A holds and B fails -> FALSE, name the test. If A fails, that magma proves nothing; go to the next test. If both hold, go to the next test. Run the tests in this order.

C0 constant magma (a*b = 0 on {0,1}): a law holds iff neither side is bare. So: A has no bare side AND B has a bare side -> FALSE.
LP0 (a*b = a): holds iff lm(L) = lm(R).
LP2 (a*b = a+1 mod 2): holds iff lm(L) = lm(R) AND ld(L) = ld(R) mod 2.
LP3 (a*b = a+1 mod 3): holds iff lm(L) = lm(R) AND ld(L) = ld(R) mod 3.
RP0 (a*b = b): holds iff rm(L) = rm(R).
RP2 (a*b = b+1 mod 2): holds iff rm(L) = rm(R) AND rd(L) = rd(R) mod 2.
RP3 (a*b = b+1 mod 3): holds iff rm(L) = rm(R) AND rd(L) = rd(R) mod 3.
SET (a*b = max(a,b) on {0,1}): holds iff vars(L) = vars(R) as sets.
PARITY (a*b = a+b mod 2): holds iff every variable has the same parity of occurrence count on both sides.
Weighted tests W1-W4: from LEAVES give each leaf a weight w(L,R), add the weights of each variable on each side (a variable missing from a side sums to 0), and compare per variable mod m. Reduce each sum to the range 0..m-1 first (-1 = 2 mod 3; -1 = 3 and -2 = 2 mod 4). Holds iff every variable's two reduced sums are equal.
  W1 (a*b = 2a+2b mod 3): w = +1 if L+R is even, -1 if odd. m = 3.
  W2 (a*b = a+2b mod 3): w = +1 if R is even, -1 if R is odd. m = 3.
  W3 (a*b = 3a+2b mod 4): if R = 0: w = +1 for L even, -1 for L odd; if R = 1: w = 2; if R >= 2: w = 0. m = 4.
  W4 (a*b = 2a+3b mod 4): if L = 0: w = +1 for R even, -1 for R odd; if L = 1: w = 2; if L >= 2: w = 0. m = 4.

=== STEP 4 - FALLBACK (no rule above fired) ===

Compute from A only: M = the smallest total occurrence count (both sides of A together) of any variable of A. S = number of * in A.L. V = number of distinct variables in A.L.
B1: M >= 2 -> FALSE. Every variable of A is pinned on both sides, so A is a weak law with many models; it rarely forces B.
B2a: else if S = 0 (A.L is bare) -> TRUE. A has a free parameter and a bare side, so it is rigid, and no listed magma separated it from B.
B2b: else if S = 1 and V = 2 (A.L is a product of two distinct variables) -> TRUE.
B2c: otherwise -> FALSE.
